What matters

  • OAuth dominates distribution, but tokens dominate first-party use. CRM, support, productivity, ads, and commerce often need OAuth for multi-tenant installs; infra, data, email, and scraping tools commonly start with API keys.
  • The easiest wins are already agent-shaped. Developer platforms, productivity tools, support desks, and ecommerce platforms have broad public APIs, clear docs, and MCP/community integration precedent, treated as a discovery signal rather than production proof.
  • The hardest blockers are not technical endpoints. Ads, fintech, Amazon SP-API, and enterprise commerce are mostly blocked by review, compliance, tenant admin approval, or paid data licenses.
  • Outreach-first apps are mostly missing a product-specific developer surface. Pumble, fanbasis, Paygent Connect, NotebookLM, and Consensus should go to outreach or partner-discovery before engineering starts.
79 apps had a practical self-serve or trial path for a developer to start research without a partnership.

Self-serve did not always mean production-ready. Google Ads, Plaid, Amazon SP-API, Meta/LinkedIn Ads, and finance platforms still need review before broad customer use.

Ship nowGitHub, Slack, Notion, Airtable, Linear, Shopify, Stripe, HubSpot, Zendesk, Intercom

Ship with caveatsGoogle Ads, Meta Ads, Amazon SP-API, Plaid, QuickBooks, Salesforce Commerce Cloud

Technically buildable, but production use needs review, admin approval, business verification, or compliance controls.

Outreach firstfanbasis, Paygent Connect, Consensus, NotebookLM, Pumble

Public developer surface is missing, narrow, unclear, or not the actual product API requested.

Design carefullySnowflake, Cloudflare, Datadog, Binance, Ramp

Powerful write actions or sensitive data make permissions, guardrails, and default read-only modes important.

Agent workflow

1

Seed

Started from the 100-app list, official domains, and developer-doc hints.

2

Fetch

evidence_agent.py visits every evidence URL, strips page chrome, and extracts text from official docs pages.

3

Extract

Deterministic rules detect OAuth, API keys, tokens, Basic auth, REST, GraphQL, webhooks, MCP, review, and gated-access signals.

4

Verify

The agent compares extracted signals with the TSV, routes low-signal rows to human review, and a 12-app sample is checked manually.

5

Package

research_agent.py emits this HTML, agent_trace.json, and the verification report for reruns.
